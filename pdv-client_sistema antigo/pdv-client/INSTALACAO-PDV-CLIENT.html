📦 PDV Client

Guia de Instalação - Chamador de Caixa Livre

📋 Requisitos

  • Windows 10 ou superior
  • Permissões de administrador (apenas para instalação)
  • Acesso à rede local (para descoberta automática do servidor)

📁 Estrutura de Arquivos

Certifique-se de que a pasta pdv-client contém os seguintes arquivos:

pdv-client/ ├── dist/ │ └── win-unpacked/ ← Pasta com o executável │ ├── PDV Client.exe │ ├── icudtl.dat │ └── ... (outros arquivos) ├── INSTALAR-PDV-CLIENT.bat ← Script de instalação └── CRIAR-ATALHO-STARTUP.bat ← Script de inicialização automática

🚀 Instalação Passo a Passo

1 Copiar a Pasta PDV Client

Copie a pasta pdv-client completa para a máquina de destino.

Você pode colocar em qualquer local temporário (ex: Desktop, Downloads).

2 Executar Instalação Principal COMO ADMINISTRADOR

Clique com botão direito em INSTALAR-PDV-CLIENT.bat

Selecione "Executar como administrador"


O que este script faz:

  • ✅ Copia os arquivos para C:\PDV-Client\
  • ✅ Cria atalho na Área de Trabalho
  • ✅ Inicia o PDV Client automaticamente
⚠️ Atenção: Se o PDV Client já estiver rodando, feche-o antes de executar a instalação. Clique com botão direito no ícone da bandeja do sistema e escolha "Sair".
3 Configurar Inicialização Automática COMO USUÁRIO NORMAL

Clique duplo normal (SEM administrador) em CRIAR-ATALHO-STARTUP.bat


O que este script faz:

  • ✅ Cria atalho na pasta Startup do usuário atual
  • ✅ PDV Client inicia automaticamente com o Windows
ℹ️ Por que dois scripts?
O primeiro precisa de admin para copiar arquivos para C:\. O segundo NÃO pode ser admin, senão cria o atalho no usuário errado (administrator em vez do operador).
✅ Instalação Concluída!
O PDV Client está instalado e configurado para iniciar automaticamente com o Windows.

⚙️ Configuração

1 Abrir Configurações

Clique com botão direito no ícone do PDV Client na bandeja do sistema (próximo ao relógio)

Selecione "Configurações"

2 Configurar Parâmetros

Número do Caixa: Digite o número do caixa (ex: 1, 2, 3...)

Tipo de Caixa: Selecione "Normal" ou "Prioritário"

Servidor: Deixe em branco para descoberta automática ou digite o IP manualmente

Pasta Compartilhada: Caminho da pasta de chamadas (padrão: \\srvsistema\GERTEC\chamada)

Tecla de Atalho: Tecla para chamar cliente (padrão: Y)

3 Salvar Configurações

Clique em "Salvar"

O PDV Client irá reconectar automaticamente com as novas configurações

🎯 Como Usar

1. Verificar Conexão:

  • 🟢 Ícone verde na bandeja = Conectado ao servidor
  • 🔴 Ícone vermelho na bandeja = Desconectado

2. Chamar Cliente:

  • Pressione a tecla configurada (padrão: Y)
  • O sistema envia a chamada para o telão
  • Aguarde o tempo de cooldown configurado antes de chamar novamente

🔧 Solução de Problemas

PDV Client não inicia automaticamente

Solução: Execute novamente o CRIAR-ATALHO-STARTUP.bat como usuário normal (sem admin)

Ícone vermelho (desconectado)

Possíveis causas:

  • Servidor do telão não está rodando
  • Firewall bloqueando a conexão
  • IP do servidor configurado incorretamente

Solução: Verifique se o servidor está ativo e tente configurar o IP manualmente

Tecla de atalho não funciona

Solução: Abra as configurações e altere para outra tecla (ex: F1, F2, etc.)

Erro "Invalid file descriptor to ICU data"

Causa: Executável foi copiado isoladamente sem os arquivos de suporte

Solução: Execute o INSTALAR-PDV-CLIENT.bat novamente — ele copia todos os arquivos necessários

🗑️ Desinstalação

1 Fechar o PDV Client

Clique com botão direito no ícone da bandeja e escolha "Sair"

2 Remover Atalho da Inicialização

Pressione Win + R e digite: shell:startup

Delete o atalho "PDV Client.lnk"

3 Remover Arquivos

Delete a pasta C:\PDV-Client\

Delete o atalho da Área de Trabalho (se existir)
